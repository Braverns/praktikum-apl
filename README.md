# Post Test Praktikum APL

Repository ini berisi program yang dibuat untuk memenuhi tugas Post Test Praktikum Algoritma dan Pemrograman Lanjut (APL).

## Deskripsi Program

Program ini dibuat sesuai dengan studi kasus yang diberikan pada saat post test.  
Program menerima input, memproses data menggunakan algoritma yang telah dipelajari, dan menampilkan output sesuai dengan ketentuan soal.

## Cara Menjalankan Program

1. Pastikan bahasa pemrograman yang digunakan sudah terinstal.
2. Jalankan file utama program melalui terminal atau IDE.
3. Masukkan input sesuai dengan format yang diminta.
4. Program akan menampilkan hasil proses di layar.

## Studi Kasus

Tuliskan deskripsi singkat soal post test di bagian ini.

Contoh:
> Program mengolah sejumlah data dan menampilkan hasil sesuai dengan algoritma yang diterapkan.

## Catatan

- Program dibuat secara mandiri.
- Tidak menggunakan library di luar standar bahasa.
- Telah diuji menggunakan beberapa variasi input.
